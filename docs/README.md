# syncman documentation

syncman keeps pairs of folders in step, in both directions, as a background
service of your user. A *job* is a text file that lists folder *pairs*, one
per line; each started job runs as its own systemd user service.

| Page | For | What it covers |
|---|---|---|
| [Install](install.md) | everyone | requirements, install, update, uninstall |
| [Using syncman](usage.md) | everyone | jobs, every command, the panel |
| [Configuration](configuration.md) | everyone | `syncman.conf`, exclude lists, several machines, the app icon |
| [How syncing works](how-it-works.md) | everyone | what is copied and deleted when, and the known gaps |
